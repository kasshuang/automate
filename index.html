🚀 快速上手

3 行代码，开始自动化

安装简单，上手零门槛，立即见效。

📦 Step 1 — 安装

点击复制命令

$ pip install automatelib

🖥️ Step 2 — 运行

$ automate run "上架闲鱼商品"
$ automate gui

🐍 Step 3 — Python API

# 命令行，一句话搞定
automate run "上架闲鱼商品"
# 或进入 GUI 界面
automate gui
# 打开 GUI 图形界面
automate gui
# 支持可视化任务编辑
# 实时查看运行日志
from automatelib import AutoMate
am = AutoMate()
am.execute("帮我上架二手iPhone 13")
