### 🚀 快速上手（第五屏）

**标题：** 3 行代码，开始自动化

**Step 1 安装**
```bash
pip install automatelib
```

**Step 2 运行**
```bash
# 命令行模式
automate run "上架闲鱼商品"

# GUI 模式
automate gui

# Python API
from automatelib import AutoMate
am = AutoMate()
am.execute("帮我上架二手iPhone 13")
```

**Step 3 享受**
```
☕ 喝杯咖啡，AutoMate 在干活
```

## 三、官网设计规范建议

**配色方案：**
- 主色：#6366F1（科技蓝紫）
- 背景：#0F172A（深空黑）
- 文字：#F8FAFC（近白）
- 强调：#22D3EE（Cyan 高亮）
- 代码区：#1E293B（深灰蓝底）

**字体：**
- 标题：Inter / 等宽中文（思源黑体）
- 正文：Inter / 系统默认中文
- 代码：JetBrains Mono / Fira Code

**交互：**
- Hero 背景：轻微粒子/渐变动画
- 能力卡片：Hover 微微上浮 + 发光边框
- 代码块：自带复制按钮
- CTA 按钮：渐变背景 + 微光效果
