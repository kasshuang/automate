# AutoMate 产品需求文档（PRD）

> 版本：v1.0 | 日期：2026-04-12 | 状态：初稿

## 一、产品概述

### 1.1 产品定位

**AutoMate** = AI + PC 自动化，面向中文用户的下一代桌面 Agent

一句话定义：**用自然语言指挥电脑自动干活，零编程基础也能玩转自动化。**

---

## 二、目标用户

### 2.1 核心用户画像

| 用户类型 | 具体描述 | 痛点 |
|---------|---------|------|
| **电商运营** | 闲鱼/拼多多小卖家、个人创业者 | 重复上架商品、回复消息、填写表格耗时 |
| **内容创作者** | 公众号/小红书/知乎作者 | 多平台发布繁琐、重复性排版操作 |
| **行政办公** | 公司职员、HR、财务 | 批量填表、数据录入、文件整理 |
| **技术用户** | Python/脚本开发者 | 需要快速搭建 PC 自动化原型 |
| **懒人用户** | 普通用户 | "这些重复操作能不能自动干" |

### 2.2 用户规模估算

- **目标市场**：中国中小企业和个人用户，PC 自动化工具潜在用户 500 万+
- **核心转化人群**：电商卖家（闲鱼/淘宝）+ 内容创作者 + 办公族
- **付费意愿**：月均 50-200 元可接受（参考剪映、Notion 订阅价）

## 三、竞品分析

### 3.1 主要竞品

| 产品 | 厂商 | 定价 | 目标用户 | 核心能力 | 缺点 |
|------|------|------|---------|---------|------|
| **UiPath** | 美国 UiPath | 免费社区版 + 企业版$500+/年 | 跨国大企业 | 流程录制、AI OCR、低代码设计器 | 笨重、全英文、中小企业用不起 |
| **Automation Anywhere** | 美国 AA | 企业版$600+/年 | 金融、大企业 | 云端编排、认知自动化 | 过于企业化 |
| **影刀 RPA** | 中国影刀 | 免费基础版 + 专业版 3600/年 | 电商企业 | 电商场景覆盖广、录制功能强 | 需要一定学习成本、AI 能力弱 |
| **影刀 AI** | 影刀 | 打包约 6000+/年 | 电商企业 | RPA+AI 组合 | 价格偏高、AI 为云端黑盒 |
| **Power Automate** | 微软 | Windows 免费 + 云端付费 | IT/企业用户 | 深度 Windows 集成 | 全英文、门槛高 |
| **Keyboard Maestro** | Mac 独占 | $36 买断 | Mac 高端用户 | 强大的触发器系统 | 仅 Mac，无 AI |

### 3.2 竞争格局图

```
AI 能力强
   ▲
   │  AutoMate ←── 我们在这里
   │  （AI 原生 + PC 本地 + 中文友好）
   │
   │  影刀 RPA
   │  （RPA 为主 + 少量 AI）
   │
   │  UiPath / AA
   │  （企业级 + 复杂）
   └─────────────────────────────────► 门槛低
                 易用性高
```

### 3.3 差异化定位

**竞品没有解决的 3 个问题，AutoMate 来填补：**

1. **"太难了"** —— RPA 产品需要学习曲线，AutoMate 用自然语言控制，0 门槛
2. **"太贵了"** —— 企业级产品定价高昂，AutoMate 面向个人用户，免费可用
3. **"不接地气"** —— 国外产品全英文，AutoMate 从 UI 到文档全中文

## 四、产品功能清单

### 4.1 核心功能（完整 Roadmap）

#### Phase 1-2 ✅ 已完成
- [x] 鼠标/键盘自动化控制
- [x] 屏幕截图 + 区域截图
- [x] 图片识别定位（find_on_screen）
- [x] 剪贴板读写
- [x] 窗口查找与激活
- [x] CLI 命令行工具
- [x] GUI 图形界面
- [x] 预设任务（闲鱼上架、发布文章、填表）

#### Phase 3 🔜 进行中（Agent 集成）
- [ ] **自然语言理解引擎**：接入 LLM（大模型），理解"帮我上架闲鱼商品"并自动规划步骤
- [ ] **智能步骤规划**：AI 根据目标描述 + 当前屏幕截图，自动生成执行步骤
- [ ] **多轮对话修正**：执行失败时 AI 自动问"哪里出问题了"并调整策略
- [ ] **上下文记忆**：记住用户习惯（如常用店铺、默认价格格式）
- [ ] **本地 OCR**：集成 PaddleOCR / EasyOCR，识别图片中的文字

#### Phase 4 🔜 插件市场
- [ ] **电商插件包**：闲鱼、拼多多、淘宝、抖音小店的垂直场景
- [ ] **内容插件包**：微信公众号、小红书、知乎、微博发布
- [ ] **办公插件包**：Excel 批量处理、文件批量重命名、邮件批量发送
- [ ] **社交插件包**：微信消息、钉钉、企业微信
- [ ] **插件 SDK**：允许用户或第三方开发自定义插件
- [ ] **插件市场网页**：展示、评分、安装量统计

#### Phase 5 🔜 云端服务
- [ ] **云端 Agent**：算力不足时，云端大模型接管复杂任务
- [ ] **任务云同步**：跨设备同步自动化任务
- [ ] **团队协作**：企业版支持共享任务库、权限管理
- [ ] **执行日志云存储**：任务执行记录云端备份

### 4.2 功能优先级矩阵（Must / Should / Could）

按 **商业价值** 和 **技术实现难度** 分为：

```
高价值 + 低难度（立刻做）：
  ✅ AI 自然语言控制（核心差异化）
  ✅ 电商场景深化（闲鱼/拼多多）
  ✅ 截图 + OCR 识别

高价值 + 高难度（规划做）：
  🔜 云端 Agent 服务（变现核心）
  🔜 插件市场（生态护城河）
  🔜 团队协作（企业版核心）

低价值 + 低难度（有资源做）：
  📋 更多预设任务
  📋 宏录制器（屏幕录制 → 自动生成脚本）

低价值 + 高难度（暂不做）：
  ❌ 移动端 App 自动化
  ❌ Linux/macOS 跨平台
```

    ↓
【付费转化】¥29/月 专业版 → 解锁 AI + 无限次数
    ↓
【持续使用】每天用 AutoMate 自动化日常工作
